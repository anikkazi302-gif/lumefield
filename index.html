How to make the full 30 seconds

  1. Open the engine above (free, no payment). Upload your reference photo as the start frame / image input.
  2. Paste the Segment 1 prompt and generate. Download the clip.
  3. For Segment 2, use the last frame of Segment 1 as the start image (save it from the clip) and paste the Segment 2 prompt. Repeat for Segment 3.
  4. Join the clips in any free editor (CapCut, DaVinci Resolve, or ffmpeg) — no re-render needed.
  5. If a segment comes out wrong, regenerate only that segment — never the whole video.

Tip: keep the subject, face, clothes and setting identical in every segment.

Guides

Short answers — no fluff.

30-second video

One plan, chained clips. Most engines make 5–10s per clip — the tool splits 30s into segments that fit the engine. Render each segment with the same Photo 1, then join them in order.

Best engine per scene

Talking / dialogue → Kling 4.0 (30s, lip-sync). Long clip + motion → Seedance 2.5 (30s). Text only → Mochi 1. Many reference photos → Seedance (30) or Vidu Q4 (15).

Same face, every clip

Photo 1 is the start frame. Upload up to 30 photos of the same face, hair and clothes. Every plan carries a CHARACTER LOCK — same face, same hair, same clothes in every frame.

Fix a bad segment

Re-render only that segment — same prompt, same Photo 1. Still wrong? Shorten the segment or switch to a shorter-clip engine. Never re-render the whole video.
